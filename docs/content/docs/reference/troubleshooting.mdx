## "Enable or re-authenticate the connector"

The plugin checked its connectors before doing anything and one of them failed.
Open the **+** menu → **Connectors** and switch the named one back on, then say
go again. Nothing was read or written in the meantime.

## The plugin does not seem to trigger

Check it is installed on the **Personal** tab of the plugin directory. If you had
**Portal Investor Notes** before, that is the old name — it will not update itself
into **Investor Meeting Summary**. See [Install the plugins](/docs/getting-started/install).

## Claude cannot find the meeting in Otter

Otter searches your own account only. If a colleague recorded the meeting, ask
them to share the conversation with you in Otter, or let them log it from their
own account.

If the meeting is there but was not found, give Claude the date, or the exact
title as it appears in Otter.

## It matched the wrong firm

Say so before you confirm, and name the right one. This is exactly why the draft
shows you the matched record. If two records look like genuine duplicates of the
same firm, that is a base cleanup worth raising rather than something to work
around.

## It says the company is not in the base

By design, neither plugin creates a firm or startup record. Add the company
through the **Enter a new startup into Airtable** form, give it a minute to sync,
then run the plugin again.

## My triage note overwrote someone else's

It should not be possible — the triage plugin reads the current value and appends
beneath it under a dated header. If you see otherwise, send the example to
Chi-Lam; that is a bug, not a setting.

## I did not want that email to go out

Reminder emails and notification emails are only set when you ask for them, and
they appear in the confirmation step before submission. Note that submitting the
CRM form does trigger the base's own notification automation independently of the
plugin.

## Something else

Questions, a note that came out wrong, or an idea for what the summaries should
include — send it to Chi-Lam.
