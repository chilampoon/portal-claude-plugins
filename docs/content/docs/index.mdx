## Set up once

Two minutes, and you never touch it again.

<Steps>
<Step n="01" title="Add the Portal marketplace">

In Claude, open **Customize → Plugins** and add a marketplace. Paste this GitHub
repository into the URL field, leave **Sync automatically** switched on, and
click **Sync**:

```
https://github.com/chilampoon/portal-claude-plugins
```

With automatic sync on, later improvements reach you without reinstalling.

<Screenshot src="/screenshots/add-marketplace.png" alt="The Add marketplace dialog with the Portal repository URL pasted in." />

</Step>
<Step n="02" title="Install a plugin">

Open the **Personal** tab in the plugin directory, find the plugin you want, and
click **Install**. Install either or both.

<Screenshot src="/screenshots/install-plugin.png" alt="A plugin card on the Personal tab with its Install button." />

</Step>
<Step n="03" title="Connect your accounts">

The first time you use a plugin, Claude asks you to sign in. Investor meeting
summary needs **Otter.ai and Airtable**; Triage note updates needs **Airtable**.
Approve with your own Portal accounts. Claude only sees what you can already see
in those tools, and it writes to Airtable as you.

If a connector is missing or a sign-in has expired, the plugin stops before
reading or writing anything and names the connector to reconnect. In a chat that
is the **+** menu → **Connectors**.

<Screenshot src="/screenshots/connect-airtable.png" width={420} alt="Claude asking you to sign in to Airtable the first time a plugin runs." />

</Step>
</Steps>
