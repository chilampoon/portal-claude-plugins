## Plugins

| Plugin | What it does |
| --- | --- |
| [Investor meeting summary](/docs/investor-meeting-summary) | After an investor meeting, turns your AI meeting notes into a structured note on the firm's record in the Venture base. |
| [Triage note updates](/docs/triage-note-updates) | Takes a triage note you wrote, as a Word doc, PDF or email, files it onto the company's Deal Flow record, moves the pipeline stage to match your decision, and replies to the notification that sends. |
| [Startup form init](/docs/startup-form-init) | Gets a new company into the base from its deck and email thread: duplicate check, every form field drafted with a source, missing founders created in HubSpot, then a pre-filled form link you submit. |

## Set up once

Two minutes, and you never touch it again.

<Steps>
<Step n="01" title="Add the Portal marketplace">

In Claude, open **Customize → Plugins** and add a marketplace. Paste this GitHub
repository into the URL field, leave **Sync automatically** switched on, and
click **Sync**:

```
https://github.com/chilampoon/portal-claude-plugins
```

With automatic sync on, later improvements reach you without reinstalling.

<Screenshot src="/screenshots/add-marketplace.png" alt="The Add marketplace dialog with the Portal repository URL pasted in." />

</Step>
<Step n="02" title="Install a plugin">

Open the **Personal** tab in the plugin directory, find the plugin you want from
the table above, and click **Install**. Install either or both.

<Screenshot src="/screenshots/install-plugin.png" alt="A plugin card on the Personal tab with its Install button." />

</Step>
<Step n="03" title="Connect your accounts">

The first time you use a plugin, Claude asks you to sign in. For example, Triage note updates needs **Airtable**, and Startup form init also needs **HubSpot** when a founder has to be created.
Approve with your own Portal accounts. Claude only sees what you can already see
in those tools, and it writes to Airtable as you.

<Screenshot src="/screenshots/connect-airtable.png" width={420} alt="Claude asking you to sign in to Airtable the first time a plugin runs." />

</Step>
</Steps>
