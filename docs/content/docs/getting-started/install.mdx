---
title: Install the plugins
description: Add the Portal marketplace in Claude and install the plugins you need.
---

Two minutes, once.

## 1. Add the Portal marketplace

In Claude, open **Directory → Plugins** and click the **+** button. Paste this
into the URL field, leave **Sync automatically** switched on, and click **Sync**:

```
https://github.com/chilampoon/portal-claude-plugins
```

If GitHub says you do not have access to the repository, ping Chi-Lam.

## 2. Install what you need

Open the **Personal** tab in the plugin directory. Install either or both:

| Plugin | Install it if you |
| --- | --- |
| **Investor Meeting Summary** | meet investors and want the notes filed in the VC CRM |
| **Triage Note Updates** | write triage notes on startups and want them on the Deal Flow record |

## If you had the old plugin

**Portal Investor Notes** was renamed to **Investor Meeting Summary**, and the
way it writes to Airtable changed. Because the name changed, your old copy will
not update itself — uninstall **Portal Investor Notes** and install
**Investor Meeting Summary** instead.

You will be asked to sign in to Otter and Airtable once more afterwards. That is
expected: the connectors are tied to the plugin's name.

## Updates

With automatic sync switched on, later improvements reach you on their own. You
do not need to reinstall anything.
